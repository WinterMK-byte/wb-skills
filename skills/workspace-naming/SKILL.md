# 工作区命名

## 背景（硬事实，别再重新调查）

- 不点「选择工作空间」时，WorkBuddy 把工作区落在 `D:\新建文件夹\<YYYY-MM-DD-HH-MM-SS>\`，没有名字。
- **目录不能重命名**：路径写死在 `C:\Users\<用户名>\.workbuddy\workbuddy.db`（实测 240+ 处）和 `.workbuddy\projects\d-新建文件夹-<时间戳>\` 里。改名会让历史会话失联。
- 唯一根治办法：建任务时点输入框左下角 **选择工作空间**，选一个自己命名的目录。
- 建议给自己定一个**统一的根目录**（例如 `<你的根目录>\`），里面放一份「读我」说明，以后所有工作区都建在它下面。
- 用户 2026-09-21 定的规矩：**以后新建的工作区都必须有自己的名字**。

## 动作

### 1. 检测（每个新会话开工第 0 步）

工作区路径匹配 `\新建文件夹\<时间戳>` → 无名，走第 2 步。
路径已经是一个有意义的名字（不是 `\新建文件夹\<时间戳>` 那种）→ 跳过，不用声张。

### 2. 命名

问一句这次工作区叫什么（给推荐名，别给空白选项）。用户给名字后：

1. 在工作区根目录写 `NAME.md`：
   ```md
   # 工作区名：<名字>
   用途：<一句话>
   创建：YYYY-MM-DD
   ```
2. 把名字记进 `.workbuddy\memory\YYYY-MM-DD.md`，将来检索靠它。
3. 提醒用户：下次建任务点「选择工作空间」，选你定的根目录下的 `<名字>`，别再走默认目录。

### 3. 禁止

- 不重命名工作区目录（会炸数据库里的路径）
- 不改 `.workbuddy\projects\` 下的映射目录名
- 不批量清理 `D:\新建文件夹\`——那是用户的 17 个历史会话，删了找不回来
