# 目录冗余核验（sha256 全量）——「能不能删」只能靠内容哈希回答

## 核心原则（顺序不能反）

1. **绝不按文件名或大小判定重复**。同名不同内容、同大小不同内容都存在，实测过。
2. **路径不同 ≠ 内容不同**。用户本地实测：`本地知识库\某高校课程资料` 与 `Resource\某高校课程资料`
   目录结构就不一样（本地缺 `作业实验\` 一层），但 1416 个文件内容完全一致。
   → 只比 relpath 会得出「1578 个独有」的**完全错误**结论。
3. **只要目录里存在 1 个「内容独有」文件，就不能整目录删**。这是硬规则，不看体积占比。
4. 盘点文档里写的「约 X GB 可清」在哈希核验前**一律视为假设**，不要转述给用户当结论。

## 执行

### 第 1 步：只读全量哈希（不写、不删、不移）

```python
# _scratch/_dupe_verify.py 骨架
import os, hashlib
def walk(root):
    out = []
    for dp, dns, fns in os.walk(root):
        dns[:] = [d for d in dns if d not in ('__pycache__', '.git')]
        out += [os.path.join(dp, f) for f in fns if os.path.isfile(os.path.join(dp, f))]
    return out
def sha256(p, buf=1 << 20):
    h = hashlib.sha256()
    with open(p, 'rb') as f:
        for b in iter(lambda: f.read(buf), b''):
            h.update(b)
    return h.hexdigest()
# 对 A、B 两棵树各建 {hash: [paths]}，A 中 hash 不在 B 里 → A 独有
```

- 4.5 GB / 约 3500 文件 → 约 2 分钟。放后台跑，别阻塞。
- 文件头用 `r"""..."""`，否则 `\ ` 之类会报 `SyntaxWarning`。

### 第 2 步：分三类出结论

| 类别 | 含义 | 处置 |
|---|---|---|
| 内容相同（hash 命中） | 真副本 | 可删 |
| 目录内全部为副本 | 整目录可清 | 走回收站 |
| **存在内容独有文件** | **不可整目录删** | 出「保留清单」+「可删清单」两份 json |

### 第 3 步：落盘（产物放被盘点目录的旁边，别放工作区）

- 文档：`<被盘点目录>\_磁盘盘点_<主题>_<日期>.md`，含「结论 + 表格 + 清单路径 + 脚本路径」
- 清单：`_清理清单_<目录名>_保留N.json` / `_可删M.json`
- 同步更新盘点文档的旧结论（写明「原文已被推翻」），别让旧数字继续流传

### 第 4 步：删除（**默认不做，等用户确认**）

`Desktop\<产出目录>` 属个人目录，适用个人文件安全规则：

- 只走**回收站**，禁止 `rm` / `rmtree` / `del /S`
- 先备份、分批 ≤10 个、每批后校验、失败立即停
- 大面积删目录时**更省事的做法是告诉用户「拖这 3 个文件夹到回收站」**，而不是写脚本

## 实测案例

> 下表是一次真实盘点的结果，**目录名已换成通用示例**；你的目录名与数字都会不同。

| 目录 | 本地/源 | 内容相同 | 本地独有 | 判定 |
|---|---|---|---|---|
| `课程资料` | 1579/1639 | 1416（1297.5 MB） | **163（313.7 MB）** | **不可整目录清** |
| `真题` | 1/10 | 1（13.1 MB） | 0 | 可清 |
| `数学复习资料` | 60/61 | 60（275.9 MB） | 0 | 可清 |
| `英语复习资料` | 62/64 | 62（249.9 MB） | 0 | 可清 |

独有文件全是 `.ppt` 课件。整目录清 = 永久丢 313.7 MB。
**只按目录体积做判断，会把 313.7 MB 不可再生资料一起删掉。**

## 顺手检查（会被漏掉的两件事）

- 两棵树 relpath 对不上时，再做一次「路径分类」：源里有同名文件但大小不同 = 版本漂移，要人工判断。
- 顺带统计「源有、本地无」的文件数 —— 若很多，说明本地只是**部分留存，不能当备份用**，这句话必须写进结论。
